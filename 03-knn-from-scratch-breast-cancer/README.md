# KNN с нуля — реализация без sklearn

Ручная реализация алгоритма k-ближайших соседей на том же датасете, что и в предыдущей работе — чтобы разобрать внутреннюю логику алгоритма, а не использовать готовую библиотеку.

## Датасет
Breast Cancer Wisconsin (Diagnostic) — тот же, что в работе 02.

## Что сделано
- Реализация функции евклидова расстояния между объектами
- Функция поиска k ближайших соседей (`get_neighbors`) — расчёт расстояний до всех точек обучающей выборки, сортировка, отбор k ближайших
- Функция классификации по голосованию большинства (`predict_classification`)
- Ручной расчёт accuracy без использования `sklearn.metrics`
- Сравнение результата ручной реализации с результатом sklearn (работа 02)

## Результат
Accuracy: **0.93** — совпадает с результатом готовой реализации sklearn, что подтверждает корректность собственной реализации алгоритма.

## Стек
Python, NumPy, Pandas
