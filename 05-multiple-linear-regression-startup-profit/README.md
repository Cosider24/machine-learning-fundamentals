# Множественная линейная регрессия — прибыль стартапов

Построение модели множественной линейной регрессии с учётом числовых и категориальных признаков для прогноза прибыли компаний.

## Датасет
50 Startups — данные о 50 компаниях: расходы на R&D, административные расходы, расходы на маркетинг, штат (категориальный признак), прибыль (целевая переменная).

## Что сделано
- Проверка данных на пропуски
- Кодирование категориального признака `State` через `OneHotEncoder`
- Матрица корреляций признаков с целевой переменной
- Разделение на train/test, обучение `LinearRegression`
- Оценка качества модели: R², MSE, RMSE
- Сравнение реальных и предсказанных значений прибыли
- Интерпретация коэффициентов регрессии

## Результат
R² (коэффициент детерминации): **0.8987**

## Стек
Python, Pandas, Scikit-learn, Seaborn, Matplotlib
