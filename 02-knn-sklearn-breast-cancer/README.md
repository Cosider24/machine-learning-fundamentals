# KNN — классификация опухолей молочной железы (sklearn)

Реализация алгоритма k-ближайших соседей для бинарной классификации опухолей на злокачественные и доброкачественные.

## Датасет
Breast Cancer Wisconsin (Diagnostic) — 569 объектов, 30 числовых признаков (радиус, текстура, площадь клеток и др.)

## Что сделано
- Предобработка данных: кодирование целевой переменной, удаление лишних столбцов, проверка на пропуски
- Разведочный анализ (EDA): pair plot по ключевым признакам
- Разделение на train/test (70/30, стратификация по классам)
- Обучение `KNeighborsClassifier` (k=5)
- Оценка качества: accuracy, confusion matrix

## Результат
Accuracy на тестовой выборке: **0.93**

## Стек
Python, Pandas, Scikit-learn, Seaborn, Matplotlib
