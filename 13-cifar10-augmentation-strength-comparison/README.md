# Сравнение силы аугментации — CIFAR-10

Эксперимент по влиянию силы аугментации (слабая / умеренная / усиленная) на качество обучения CNN.

## Датасет
CIFAR-10 (см. работу 10).

## Что сделано
- Создание трёх вариантов аугментации с разной интенсивностью преобразований (поворот, зум, сдвиг, изменение контраста)
- Визуальное сравнение результата всех трёх вариантов на одном изображении
- Обучение трёх отдельных CNN-моделей — по одной на каждый вариант аугментации
- Сравнение графиков обучения (accuracy/loss) между моделями
- Оценка каждой модели на тестовой выборке, сравнительная таблица результатов
- Анализ конкретных ошибок лучшей модели (confusion matrix, визуализация неверных предсказаний)

## Результат
| Сила аугментации | Test Accuracy |
|---|---|
| Слабая | **75.55%** (лучший результат) |
| Умеренная | 69.63% |
| Усиленная | 59.72% |

Слабая аугментация оказалась оптимальной — усиленная аугментация чрезмерно искажает изображения и мешает обучению, а не помогает: модель хуже обобщает, когда объекты становятся плохо различимыми.

## Стек
Python, TensorFlow/Keras, Seaborn, Matplotlib
