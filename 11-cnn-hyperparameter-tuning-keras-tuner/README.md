# Подбор гиперпараметров CNN — Keras Tuner

Автоматический подбор архитектуры свёрточной нейросети для CIFAR-10 вместо ручного перебора вариантов.

## Датасет
CIFAR-10 (см. работу 10).

## Что сделано
- Постановка базовой CNN-модели (работа 10) как отправной точки
- Описание пространства поиска гиперпараметров: количество фильтров в свёрточных слоях, наличие третьего свёрточного блока, число нейронов в полносвязном слое, коэффициент Dropout, learning rate
- Настройка `keras_tuner.RandomSearch` для автоматического перебора архитектур по метрике `val_accuracy`
- Проведение серии экспериментов (Trials), сравнение полученных конфигураций
- Обучение финальной модели с лучшими найденными гиперпараметрами

## Результат
Лучшая найденная конфигурация достигла **val_accuracy ≈ 0.82** в процессе поиска — заметный прирост относительно базовой архитектуры из работы 10 (accuracy 70.78%).

## Стек
Python, TensorFlow/Keras, Keras Tuner, Scikit-learn
