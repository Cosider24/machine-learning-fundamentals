# MNIST — исследование устойчивости модели к шуму

Продолжение работы с MNIST: проверка, насколько обученная модель устойчива к искажению входных данных, и попытка повысить эту устойчивость через обучение на зашумлённых примерах.

## Датасет
MNIST (см. работу 08) + искусственно добавленный гауссов шум к тестовой выборке.

## Что сделано
- Повторное обучение базовой полносвязной сети на чистых данных
- Добавление гауссова шума к тестовым изображениям, визуальное сравнение "до/после"
- Оценка точности модели на зашумлённых данных в сравнении с чистыми
- Анализ конкретных ошибок — какие цифры чаще всего путаются после зашумления
- Обучение второй модели непосредственно на зашумлённых данных для повышения устойчивости, сравнение результатов

## Результат
| Сценарий | Accuracy |
|---|---|
| Чистые тестовые данные | 97.69% |
| Зашумлённые данные (модель, обученная на чистых) | 67.58% |
| Зашумлённые данные (модель, обученная на зашумлённых) | 82.99% |

Обучение на зашумлённых данных существенно повышает устойчивость модели к искажениям входа.

## Стек
Python, TensorFlow/Keras, NumPy, Matplotlib
