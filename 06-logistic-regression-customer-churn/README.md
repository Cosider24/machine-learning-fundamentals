# Логистическая регрессия — прогноз оттока клиентов

Построение модели логистической регрессии для предсказания вероятности оттока клиентов телеком-компании и анализ влияния признаков.

## Датасет
Customer Churn — данные о клиентах: демография, подключённые услуги, тип контракта, способ оплаты, ежемесячные и общие платежи, факт оттока (Churn).

## Что сделано
- Предобработка: кодирование целевой переменной, удаление неинформативных столбцов, приведение типов
- Кодирование категориальных признаков через `get_dummies`
- Масштабирование числовых признаков (`StandardScaler`) для устранения перекоса по шкале
- Обучение `LogisticRegression`
- Оценка через confusion matrix и accuracy
- Анализ коэффициентов модели — какие признаки сильнее всего влияют на отток (например, тип интернет-соединения, способ оплаты)

## Стек
Python, Pandas, Scikit-learn, Seaborn, Matplotlib
