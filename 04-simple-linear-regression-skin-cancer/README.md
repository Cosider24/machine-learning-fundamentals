# Простая линейная регрессия — смертность от рака кожи

Построение модели простой линейной регрессии для предсказания смертности от рака кожи по широте местности.

## Датасет
Данные по 49 штатам США (1950 г.): широта, долгота, близость к океану, смертность от рака кожи (на 10 млн населения).

## Что сделано
- Загрузка и парсинг данных с внешнего источника
- Визуализация зависимости смертности от широты
- Обучение модели `LinearRegression` (sklearn)
- Визуализация линии регрессии поверх исходных данных
- Интерактивный ввод значения широты для получения прогноза

## Стек
Python, Pandas, Scikit-learn, Matplotlib
