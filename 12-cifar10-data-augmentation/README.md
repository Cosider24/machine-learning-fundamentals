# Аугментация данных — CIFAR-10

Применение аугментации изображений при обучении CNN для повышения обобщающей способности модели.

## Датасет
CIFAR-10 (см. работу 10).

## Что сделано
- Визуализация примеров изображений по классам
- Создание слоя аугментации (`RandomFlip`, `RandomRotation`, `RandomZoom`, `RandomTranslation`, `RandomContrast`)
- Визуальное сравнение изображений до/после аугментации
- Обучение CNN с применением аугментации "на лету" (аугментация активна только во время обучения)
- Построение графиков обучения, оценка модели на тестовой выборке
- Анализ влияния аугментации на переобучение по сравнению с базовой моделью (работа 10)

## Результат
Accuracy на тестовой выборке: **72.07%** — прирост по сравнению с базовой моделью без аугментации (70.78%).

## Стек
Python, TensorFlow/Keras, Matplotlib
