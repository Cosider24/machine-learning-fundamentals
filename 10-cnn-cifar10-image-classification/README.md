# CNN — классификация изображений CIFAR-10

Применение свёрточной нейронной сети (CNN) для классификации цветных изображений по 10 классам.

## Датасет
CIFAR-10 — 60 000 цветных изображений 32×32 пикселя, 10 классов (самолёт, автомобиль, птица, кот, олень, собака, лягушка, лошадь, корабль, грузовик).

## Что сделано
- Нормализация изображений, one-hot encoding меток
- Разделение обучающей выборки на обучающую и валидационную
- Построение CNN: 2 свёрточных блока (Conv2D + MaxPooling2D) + Dense + Dropout + выходной слой
- Обучение и построение графиков accuracy/loss (обучение vs валидация)
- Оценка на тестовой выборке
- Разбор роли каждого слоя (Conv2D, MaxPooling2D, Flatten, Dropout) и признаков переобучения по графикам

## Результат
Accuracy на тестовой выборке: **70.78%**

## Стек
Python, TensorFlow/Keras, Matplotlib
