# Разведочный анализ данных — Iris Dataset

Знакомство с pandas: загрузка данных, базовая статистика, фильтрация, визуализация и объединение таблиц на классическом датасете ирисов Фишера.

## Датасет
Iris Dataset — 150 образцов трёх видов ириса (setosa, versicolor, virginica), 4 числовых признака: длина/ширина чашелистика и лепестка.

## Что сделано
- Загрузка данных, проверка типов и пропусков
- Описательная статистика по видам (`describe`, `groupby`, `mean`, `median`, `agg`)
- Фильтрация и срезы (`loc`, `iloc`, условные выборки)
- Визуализация: гистограммы, KDE-графики, pie chart, box plot по видам
- Feature engineering: производные столбцы (`is_large_flower`, категоризация по длине чашелистика)
- Объединение таблиц (`merge` vs `concat`) — разбор разницы между операциями
- Экспорт и чтение данных через Excel (`to_excel` / `read_excel`)

## Стек
Python, Pandas, Matplotlib
