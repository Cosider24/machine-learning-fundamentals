# Полиномиальная регрессия и переобучение

Исследование полиномиальной регрессии как расширения линейной модели на нелинейной зависимости, демонстрация эффекта переобучения при росте степени полинома.

## Датасет
Синтетические данные: зависимость энергопотребления от температуры окружающей среды (параболическая зависимость с шумом — минимум расхода при ~20°C).

## Что сделано
- Визуализация исходной нелинейной зависимости
- Обучение линейной регрессии и оценка её недостаточности (низкий R²) на нелинейных данных
- Обучение полиномиальных моделей степеней 2, 3, 5, 8
- Сравнение R² и формы кривой для каждой степени
- Анализ момента, с которого модель начинает переобучаться (высокая степень → нестабильное поведение, кривая "гоняется" за каждой точкой)

## Стек
Python, Pandas, NumPy, Scikit-learn, Matplotlib
